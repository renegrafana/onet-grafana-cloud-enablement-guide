3. AWS Partnership & Jakarta Data Residency

🇮🇩 Grafana Cloud is Available in Jakarta

Grafana Cloud launched in the AWS Asia Pacific (Jakarta) region (ap-southeast-3) in November 2024 — making it the first observability platform hosted specifically in that AWS region. Indonesian customers can store and process their data locally.

The AWS Partnership

  • Strategic relationship: Grafana Labs has a deep, long-term partnership with AWS. All new Grafana Cloud stacks are deployed on AWS infrastructure by default.
  • AWS Marketplace: Customers can purchase Grafana Cloud directly through the AWS Marketplace, drawing from existing AWS Enterprise Discount Programs (EDP) or committed spend — making procurement frictionless.
  • Amazon Managed Grafana: AWS also offers Amazon Managed Grafana (AMG) — a managed service for visualization built on Grafana Enterprise. This validates AWS's trust in Grafana as core observability infrastructure.
  • Co-selling: Grafana Labs and AWS co-sell in the field. AWS sales teams actively recommend Grafana Cloud as the observability solution for their customers.

Why Jakarta Matters

  • Data sovereignty: Indonesian regulations increasingly require local data processing and storage. The Jakarta region satisfies these requirements natively.
  • Low latency: In-country hosting means faster dashboard loads, quicker alert evaluations, and lower network overhead for Indonesian users.
  • Compliance: For government-linked enterprises and regulated industries, in-country data residency is often a hard requirement. Grafana Cloud meets this out of the box.

4. What is Grafana Cloud?

Grafana Cloud is a fully managed (SaaS), open, and composable observability platform. It enables teams to collect, correlate, and act on all their operational data — metrics, logs, traces, profiles, and more — from a single platform.

Powered by Grafana Labs' open-source projects — Grafana (visualization), Loki (logs), Mimir (metrics), and Tempo (traces) — it supports 180+ data sources and 100+ pre-built solutions. Customers don't have to rip and replace — Grafana connects to what they already have.

The LGTM+ Stack — Know This Acronym

Loki (Logs) · Grafana (Visualization) · Tempo (Traces) · Mimir (Metrics) — plus k6 (load testing), Alloy (agent), Pyroscope (profiling), Faro (frontend), OnCall + IRM (incident response). All open-source foundations, managed as a unified cloud service.

Product Portfolio

Core

Grafana (Visualization & Alerting)

The world's most popular open-source dashboard platform. 180+ data source plugins. Unified alerting across all data. AI Assistant for natural-language querying and dashboard creation.

Core

Cloud Metrics (Mimir)

Scalable Prometheus-compatible metrics backend. 13-month retention included on Pro tier. Adaptive Metrics automatically trims unused series to reduce cost.

Core

Cloud Logs (Loki)

Label-indexed log aggregation — cheaper than full-text indexing at scale. LogQL query language. Adaptive Logs for automatic cost optimization.

Core

Cloud Traces (Tempo)

Distributed tracing backend. OTel-native. TraceQL for advanced querying. Adaptive Traces for intelligent tail-sampling. No proprietary SDK required.

Solution

Application Observability

Full APM for distributed systems. Automatic entity discovery, 100+ contextual dashboards, AI-guided root cause analysis. Built on OpenTelemetry.

Solution

Kubernetes Monitoring

Single Helm chart deployment. Pre-built dashboards for clusters, nodes, pods, and workloads. Consumption-priced — scaling pods down scales the bill down.

Solution

Grafana IRM (Incident Response)

Includes Grafana OnCall and Grafana Incident. Unified alerting → routing → on-call → incident management. $20/active user (vs. $30/seat for Datadog).

Solution

Performance Testing (k6)

Open-source load testing tool, now fully integrated into Grafana Cloud. Script once, use for load testing in CI/CD and synthetic monitoring in production.

Solution

Frontend Observability (Faro)

Real User Monitoring (RUM) built on the open-source Faro SDK. Web Vitals, error tracking, session-to-trace correlation. OTel-native, no proprietary agent.

Solution

Continuous Profiling (Pyroscope)

Always-on profiling for Go, Python, Java, Rust, and more. eBPF auto-instrumentation via Alloy — zero code changes. Flame graph AI for automatic interpretation.

Capability

Grafana Assistant (AI)

AI that builds dashboards from screenshots, queries data in natural language, powers automated incident investigations, and interprets flame graphs. Works across ALL connected data sources.

Capability

Adaptive Telemetry

Automatically optimizes telemetry across metrics, logs, traces, and profiles — trimming what you don't need so you only pay for what matters. Unique to Grafana.

2

AI That Makes Everything Easier

People used to say "Grafana is powerful but hard to learn." That is no longer true. Our AI — called Grafana Assistant — makes it easy for anyone to get started.

Here is what Grafana Assistant can do:

  • Build dashboards from a screenshot: Take a photo of an existing dashboard or a drawing on a whiteboard — Grafana Assistant will build a real, working dashboard from it. McDonald's rebuilt a dashboard that took 2 months by hand — in just a few minutes using AI.
  • Ask questions in plain English: Instead of writing complex queries, users can type a question like "Show me the top 5 servers with highest CPU usage" and get the answer instantly.
  • Investigate incidents automatically: When something breaks, Grafana Assistant starts investigating before you even open your laptop. By the time you sit down, it has already built a list of possible causes with supporting evidence.
  • Works with ANY data source: Grafana AI works across all 180+ connected data sources — not just Grafana's own data. Datadog's AI only works with Datadog data. Dynatrace's AI only works with Dynatrace data. Grafana AI works with everything.

"We built a dashboard by hand over two months. Then we rebuilt the same thing with AI Assistant in minutes."

— McDonald's, live on a call with Grafana
Why this matters to your customer

AI removes the learning curve. New users can be productive on day one. This is especially important for teams that do not have deep Grafana experience — the AI helps them build dashboards, write queries, and find problems faster.

3

Open Standards — No Vendor Lock-in

Grafana is built on open-source technology and open standards like OpenTelemetry (OTel) and Prometheus. This means:

  • No proprietary agent: Grafana uses Alloy, an open-source agent. Datadog and Dynatrace use their own proprietary agents. If you want to leave Datadog, you have to remove their agent and re-instrument everything — that is a big, expensive project.
  • Your data is yours: With Grafana, your data is stored in open formats. You can export it, move it, or query it with standard tools. You are never trapped.
  • Instrument once, use forever: If you set up OpenTelemetry today, that instrumentation works with Grafana, but it also works with any other OTel-compatible platform. If you ever leave Grafana, your instrumentation stays.

"Instrument once with OTel and you own that instrumentation forever — if you ever leave Grafana, your telemetry comes with you. That is not true of a proprietary agent."

— Grafana positioning vs. competitors

"We have an aversion to vendor lock-in... we don't perceive Grafana as that type of vendor, unlike Datadog."

— Staysure (insurance company)
Why this matters to your customer

Many customers have been trapped by vendors before. They signed a contract, built everything on a proprietary platform, and then found it very expensive and difficult to leave. Grafana removes that risk completely. For companies that follow standards like ISO or COBIT, open standards alignment is often a hard requirement.

4

One Complete Platform — Not Pieces You Stitch Together

Some companies try to build their own observability stack by combining separate tools — one tool for metrics, another for logs, another for traces. This approach has big problems:

  • It is hard to connect data across different tools during an incident
  • Each tool has its own UI, its own query language, its own billing
  • The engineering team spends time maintaining infrastructure instead of building products

Grafana Cloud gives you everything in one platform: metrics, logs, traces, profiling, alerting, incident response, load testing, and frontend monitoring. All connected. All correlated. All managed by Grafana — so your team does not have to manage it.

"ClickHouse is a database you have to build a house on top of. Grafana is a fully furnished, move-in-ready house."

— A customer comparing DIY vs. Grafana Cloud
Why this matters to your customer

Customers want to solve problems, not build infrastructure. Grafana Cloud is ready to use immediately. Almost 1,000 engineers at Grafana Labs are building and improving the platform every day — that is a team your customer does not have to hire.

5

Clear, Predictable Pricing — No Surprise Bills

This is the reason that comes up in almost every competitive deal. Customers are tired of unpredictable bills from Datadog, Splunk, and New Relic.

The problem with competitors:

  • Datadog charges per host + per metric + per GB of logs + per event. Each dimension adds cost. Customers regularly see bills 40–80% higher than they expected.
  • Splunk charges per GB of data ingested. High log volumes = very high bills.
  • Many customers start "data dieting" — they reduce log retention from 30 days to 7 days, turn off features, or stop collecting data they need — just to control costs. This hurts their ability to find and fix problems.

How Grafana is different:

  • Consumption-based pricing: You pay for what you actually use. No per-host fees.
  • Adaptive Telemetry: This is a feature unique to Grafana. It automatically identifies and removes data you are not using — across metrics, logs, traces, and profiles. This means you can collect more data while paying less.
  • Cost calculator: Before you sign anything, you can see exactly what the bill will be.

"Datadog's billing model forced us to cut data that directly hurt our ability to detect and fix problems."

— Limble

The Trade Desk calls Adaptive Telemetry the "Save Money button."

— The Trade Desk (saved ~$1.74M/year)
Why this matters to your customer

For any customer comparing Grafana vs. Datadog, cost is usually the biggest factor. Grafana's pricing is simple and predictable. There are no surprise charges. And Adaptive Telemetry actively reduces waste — something no other vendor can do across all four signal types (metrics, logs, traces, profiles).
